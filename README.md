# Ecoliderazgo y manejo de conflictos

Presentación académica interactiva del Taller de Educación Ambiental de la Universidad Autónoma Gabriel René Moreno.

Incluye escenas animadas e interactivas, desarrollo conceptual, profundización académica y enlaces a las ocho fuentes del informe.

## Publicación con GitHub Pages

1. Subir `index.html` y `.nojekyll` a la raíz del repositorio.
2. En **Settings → Pages**, elegir **Deploy from a branch**.
3. Seleccionar la rama que contiene los archivos y la carpeta **/ (root)**; guardar.
4. Abrir el enlace que muestre GitHub Pages cuando finalice el despliegue.

## Uso

La presentación está contenida en un solo archivo y también funciona abriendo `index.html` localmente. Los elementos y etiquetas de las escenas responden a clics. Se puede volver a pulsar una selección o usar Escape para limpiarla. El botón **+** abre la profundización académica.

La versión publicada corresponde al archivo final aprobado, con las fuentes ajustadas para mostrarse completas.
